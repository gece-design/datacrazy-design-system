Onboarde um produto EXISTENTE no Kill Front-End.

Carregue a skill `kill-front-end` (cenários B/C). Rode `fw-audit` para
diagnosticar e classificar o produto com evidências; após o humano confirmar
o cenário, rode `fw-onboard` no modo correspondente (pareamento para B,
engenharia reversa para C). Ao final do onboarding, o produto fica pronto
para o modo `new-screens`.
