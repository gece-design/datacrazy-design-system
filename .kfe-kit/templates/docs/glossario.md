# Glossário — <produto>

Um conceito = **um** nome. O nome daqui é o que aparece no Figma, no código,
na doc e na conversa com o cliente. Sinônimo é dívida.

Idioma decidido na etapa STACKS: <PT | EN> — ver [01-arquitetura.md](01-arquitetura.md).
